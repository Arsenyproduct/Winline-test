# Winline, пополнение счёта (прототип)

Кликабельный прототип тестового задания. Один файл index.html, без сборки.

- Телефон: сценарий на весь экран.
- Десктоп: телефон по центру на тёмно-сером фоне, слева заголовок, описание и переключатель сценариев.
- Автосценарии: сумма 13 BYN даёт отказ банка, 66 BYN даёт "не хватает средств", ЕРИП даёт "проверяем платёж", остальное успех.

GitHub Pages: положить index.html и .nojekyll в корень репозитория и включить Pages для ветки main.
